# 8-week coding plan (interview is distant / rebuilding from cold)

Same pattern-first structure as 4w, paced to build durable recall and add breadth.
Each session: **20-min template review -> 1 easy warm-up -> 1-2 mediums**, 4-5 sessions/week.

- **Weeks 1-2 — core linear patterns:** arrays-hashing, two-pointers, sliding-window,
  stack, strings, design. Two passes: solve, then re-solve from a blank file a day later.
- **Weeks 3-4 — trees & graphs:** trees-bfs-dfs, graph-bfs-dfs, graph-topo, matrix.
  Internalize BFS/DFS/topo templates cold; connect topo-sort to DecisionCanvas.
- **Weeks 5-6 — dp & priority structures:** dp-1d, heap, intervals, binary-search.
  Introduce hards deliberately (1-2/week); write the recurrence before coding.
- **Week 7 — role practical:** log-parsing / state-machine problems mapped to your real
  HMC/K2 work, plus debug/code-review exercises. Build one small end-to-end practical task.
- **Week 8 — mocks & consolidation:** 3-4 timed mock rounds, narrate throughout; spaced
  re-review of every pattern's template; polish talking-points.

By week 6 you should recognize the pattern within ~60s and template it from memory.
